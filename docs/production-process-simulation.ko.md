# Heather 생산공정관리

Heather의 생산공정관리는 Schizochytrium-like thraustochytrid 기반 DHA 공정을 **연구용으로 시뮬레이션**합니다. 실제 배양기, 펌프, 밸브, 온도 제어기를 제어하지 않으며 실제 배양 결과를 보증하지 않습니다.

사용자는 자연어로 단계형 fed-batch 조건을 입력하고, 해석된 계획을 확인한 후에만 실행합니다. 결과는 사용자 소유 Supabase 행으로 저장되며, 시계열·이벤트·분석·추천·Research Memory 후보가 분리됩니다.

기본 profile은 `DEMO_SYNTHETIC_SAFE_V1`입니다. 이는 문헌 범위에 맞춘 합성 데모 profile이며 특정 균주의 최적 레시피가 아닙니다. 기본 생물은 광합성형 미세조류로 단정하지 않는 해양성 종속영양 미생물이며, 광량은 기본 계산에 사용하지 않습니다.

실행 순서: `생산공정관리` → 내용 입력 → `조건 해석` → 자동 보완·경고 확인 → `사용자 승인 후 시뮬레이션 실행` → 시간대별 결과·권장 수확시점·다음 실험 확인.

실제 실험으로 확장하려면 균주 동정, 배양기 kLa 보정, 센서 교정, 오염 관리 SOP, 반복 배양 및 안전·규제 검증이 필요합니다.
