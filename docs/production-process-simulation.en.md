# Heather Production Process Simulation

Heather's production-process area is a **research-only simulation** of a DHA process based on a Schizochytrium-like thraustochytrid. It never controls physical cultivation equipment and does not guarantee a culture outcome.

Users review a parsed staged fed-batch plan before approving a deterministic run. Results, timepoints, events, analysis, recommendations, and a Research Memory candidate are stored separately under the authenticated user.

`DEMO_SYNTHETIC_SAFE_V1` is a literature-range synthetic demo profile, not an optimum recipe for a named strain. The default organism is not treated as a photosynthetic microalga; light is not part of the base calculation.
