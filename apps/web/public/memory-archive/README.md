# Heather Memory Archive

This directory is an isolated static memory-archive application.

- `index.html` is a minimal loader used by the Heather dashboard iframe.
- `archive.part1.txt` through `archive.part6.txt` contain the compressed standalone archive bundle.
- The module does not import or call Heather AI, memory, research, database, or API code.
- Browser-side archive data remains scoped to the archive document.
